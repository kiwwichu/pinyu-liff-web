## 這一版可以測試

- 以 LINE 帳號驗證 OWNER／ADMIN 身分。
- 在手機、平板及電腦寬度查看響應式後台。
- 概覽與訂單資料頁主要顯示服務日期前後三個月內的需求單；任何服務日期早於今天但尚未完成／取消的逾期需求單，即使超過三個月也會保留並固定排在最上方。其餘需求單再依最接近今天的服務日期排序。
- 查看已匯入 Supabase 的舊訂單資料，並依需求單號合併不同服務項目。
- 搜尋飼主、毛孩、訂單編號、服務與保姆。
- 預設顯示前後三個月與逾期未完成需求單，並可切換全部歷史資料、依狀態篩選或只查看 DEMO 訂單。
- 查看訂單服務單價、次數、小計、車馬費、小費、折扣前總價、折扣、已付與未付尾款；列表將未付尾款放左側、總金額放右側。
- 新增／編輯訂單可填訂單來源、服務承接者、平台費或抽成係數；LINE、毛小愛、Petbacker 與其他來源會保留在需求單上。
- 淨收入分兩條算法：本人服務時扣除外部平台費；其他保姆服務時，以 Pinyu 抽成減去客戶折扣計算。車馬費與小費不列入 Pinyu 對保姆的抽成基礎。
- 訂單卡片與明細顯示本單淨收入；明細同時列出折扣前總價、折扣係數、折扣金額、抽成／平台費、保姆應得與需求單總額。
- 訂單卡片的服務日期、保姆、訂單來源與服務項目在桌機／平板優先排成同一列；手機才改為兩欄換行。
- 訂單卡片的金額不再拆成三欄：未付尾款獨立提示，右側依序顯示本單淨收入與訂單總額。舊單的折扣總額會由服務小計、車馬費、小費及折扣係數重新辨識，避免匯入欄位顛倒時把折扣前金額誤當成交總額。
- 訂金預設以折扣後總額的 `0.5` 試算，可改係數或填客製應付訂金；右側即時顯示應付訂金、已付、尚缺訂金與未付尾款。歷史訂單保留建立當時的比例。
- 毛小愛訂單視為客戶已由平台付款，因此客戶未付尾款固定為 `0`；尚未匯給 Pinyu 的金額另外顯示為「平台待撥款」，不再混入客戶欠款。
- 訂單列表一列顯示一張需求單並放大主要文字；明細頂部直接顯示家庭編號，內容區不重複欄位，金額摘要將需求單總額放在最下方。寬螢幕採「左側服務內容、右側狀態與金額」，手機自動改回單欄。
- 搜尋家庭時優先顯示近期服務家庭，不使用可能已過期的行政區排序。
- 從既有家庭與毛孩建立測試訂單，或建立新的 DEMO 家庭與毛孩。
- 新增訂單使用單一日曆按鈕：第一次選擇是單日，繼續選第二天就是日期區間，不另設單日／區間切換。
- 同一張需求單可按「新增其他服務類別」加入最多 12 個服務項目，共用家庭、毛孩、服務日期、狀態、車馬費、小費、折扣與已付金額。每個服務仍可分別設定時間方案、單價、次數、保姆與指定時間。
- 服務選單起始頁為唯讀價目表，依服務大項彙整時間方案與新舊客價格；按下編輯後才顯示輸入欄位，服務名稱只需填寫一次。
- 以到府照顧、遛狗散步、長時間陪伴、家訪、餵藥、多貓家庭快速選擇服務。
- 先選服務類別及時間方案，再依新客／舊客帶入預設單價；到府照顧新客預設為 30 分 $550、45 分 $750、60 分 $800，也可輸入客製價格與原因。
- 家訪直接作為服務類別使用新／舊客價目，不再另外填一筆「家訪費」。
- 折扣使用直觀係數：原價填 `1`、九折填 `0.9`、八五折填 `0.85`。
- 保姆使用下拉選擇，必填欄位會標示提醒；中文系統字體、內文字級與行高已提高，方便手機與電腦閱讀。
- 標準單價由服務、時間方案及新舊客自動帶入並鎖定；需要調整時使用客製單價及原因。
- 選中訂單後顯示鉛筆編輯及發送通知按鈕；單項或多項 DEMO 需求單都可編輯及新增服務，通知不會真的送出。
- 在「服務選單設定」新增、刪除、修改服務類別、分鐘數及新／舊客單價。
- 編輯已建立的 DEMO 訂單。
- 左側新增「服務評價」與「我的資料」。服務評價可依關鍵字及星等篩選，查看總評、文字回饋與五個細項；全部維持唯讀。
- 服務評價包含「完整後台」及「截圖分享版」。分享版只列出已同意匿名公開的評價，隱藏飼主、家庭、訂單、LINE、聯絡方式、日期與行程資料，並提供乾淨截圖模式。
- 「我的資料」顯示兩個收入數字：「目前淨收入」只計本月已完成服務，「本月淨收入」計入服務開始日在本月的全部非取消需求單；概覽保留本月淨收入快捷卡片。
- 點選收入卡會展開逐筆明細，分成「我自己服務」及「其他保姆抽成」。其他保姆抽成卡會顯示需求單號、保姆、服務日期、來源、訂單總額、適用抽成比例、我的抽成及實際淨收入，並可繼續開啟完整需求單。
- 「我自己服務」與「其他保姆抽成」都維持精簡的一列式卡片；保姆卡額外列出折扣後訂單總額、抽成比例、我的抽成及實際淨收入。即使目前選擇「目前淨收入」，抽成區仍會列出本月尚未完成的保姆訂單，並標示尚未計入目前淨收入，避免訂單完全消失。
- 舊資料若是其他保姆承接、但尚未登記抽成比例，會顯示「抽成比例待設定」且暫不計入 Pinyu 淨收入，避免把保姆服務總額誤認成 Pinyu 抽成。
- 左側新增「保姆管理」。每位保姆可新增抽成比例與生效日期；每次調整都會新增一筆歷史版本，記錄比例、適用區間、實際設定時間及調整原因，不會覆蓋前一筆。
- 每位保姆的管理卡可展開「訂單歷史」，以相同的需求單卡片查看該保姆承接的訂單、總額、抽成比例及 Pinyu 淨收入。
- 保姆管理的訂單歷史固定一列一張需求單，不使用左右雙欄。
- 新增／編輯其他保姆的訂單時，後台會依服務開始日及保姆姓名，自動找出當天有效的抽成比例。新訂單會將 `sitter_id`、抽成歷史 `rate_id`、比例及生效日存入訂單快照，之後改比例不會回頭改舊訂單。
- 匯入的舊訂單若沒有比例快照，會依服務日期對照不可覆蓋的抽成歷史；仍找不到比例時才維持「抽成比例待設定」。
- 「新增訂單」改為後台主操作：桌面側欄、右上角及手機底部都有醒目的品牌藍入口，並保留 DEMO 標示。
- 桌面左側將日常工作放在上方，「我的資料」與「服務選單設定」移到下方；右上角頭像／名稱也可直接開啟「我的資料」。
- 「家庭與毛孩」可依家庭編號、飼主姓名、毛孩姓名或電話末碼搜尋；近期家庭卡片可直接點開、修改基本資料。
- 地址與電話拆到受保護資料表，不會出現在家庭清單或啟動資料中；目前只有 OWNER 點開單一家庭時才由 Cloudflare 後端讀取，關閉視窗即清除畫面內容。
- 一個家庭可有多隻毛孩；家庭檔案、合約草稿與家訪工作台都會列出該家庭全部毛孩，不假設只有一隻。
- 家庭檔案可建立 0821 合約草稿，先輸入基本資料與經飼主確認的緊急處置摘要；明確勾選內容由系統保存，不交給 AI 判斷。
- 家庭檔案可建立家訪紀錄，設定日期、狀態、進門方式、環境與共同事項，並為每隻毛孩分別記錄健康、用藥、餵食、行為、碰觸限制及散步／如廁資訊。
- 後續家訪費使用「保姆提出金額與原因、待討論、已確認或免收」流程，不自動套用固定收費。
- OWNER「品伃」同時建立為本人保姆身分；「保姆管理」改為「保姆與排班」，同一頁可管理品伃及合作保姆的整天／指定時段排班，不需另開排班 Demo。
- 訂單頁新增灰色輕量分類：全部、待執行、待發送通知、未付錢，並在名稱旁顯示需求單數量。
- 根網址改為統一品牌入口；LINE 登入後由後端依 OWNER／ADMIN、保姆、會員身分分別導向管理後台、保姆工作台或客戶歷史紀錄。未綁定帳號停留在初步需求流程。
- 公開預約流程改為人工承接評估：先看服務圖文，再填毛孩數量、服務內容、多個時間方案、日期、距離與捷運資訊。7 公里外仍可送出並轉介其他保姆，不會被系統直接拒絕。
- 服務流程與預約規則、隱私與安全說明改成站內小視窗；正式送出前再次確認不承接傳染性疾病、重症或需要持續醫療監測的毛孩。

## 安全隔離

- 匯入的舊訂單在 Demo 階段維持唯讀。
- 測試訂單使用 `DEMO-` 開頭的獨立編號，並保存 `legacy_data.demo=true`。
- 測試訂單不寫回 Google Sheet。
- 測試訂單不呼叫 Apps Script。
- 測試訂單仍不直接建立 Google Calendar 事件；改成在確認為「待執行」時建立安全同步佇列，待 Google 一次性授權完成後才由後端送出。
- 預約頁改成四步驟手機優先流程：毛孩需求、日期與服務、地區交通、確認送出；新客送出後建立 Supabase 預約需求，後台鈴鐺顯示尚未查看數量。
- 保姆月班表可設定早／午／晚快捷時間、每週固定忙碌、單日時段、緩衝時間及每月需求單上限；品伃預設週一至週五 09:00–18:00 為固定忙碌。
- 測試訂單不發送 LINE 訊息。
- Supabase secret key 只存在 Cloudflare Worker secret，瀏覽器端沒有資料庫密鑰。

## 建議測試順序

1. 開啟概覽，確認數量與畫面是否容易理解。
2. 在訂單頁搜尋一位熟悉的飼主或毛孩，核對舊資料。
3. 打開一張舊訂單，確認欄位名稱、價格與未付尾款的呈現。
4. 新增一張一般 30 分鐘測試單，確認新／舊客單價、`單價 × 次數`、車馬費與總額。
5. 再新增一張客製價格測試單，填寫客製原因。
6. 修改剛建立的 DEMO 訂單，確認更新結果。
7. 分別以手機及電腦操作，記錄不順手或看不懂的地方。
