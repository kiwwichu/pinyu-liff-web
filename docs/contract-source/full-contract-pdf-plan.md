# 完整合約 PDF 線上簽署規格

來源檔：`0821快樂小狗 Pinyu 寵物保姆服務合約 .docx`

## 最終呈現方式

- 保留原合約的完整條文、頁次、段落與版面，不把合約改寫成精簡網頁摘要。
- 先將 DOCX 固定輸出為版本化 PDF，再於 PDF 的原空白位置覆蓋可輸入欄位。
- 姓名、電話、地址、毛孩資料、獸醫院等欄位使用鍵盤輸入。
- 事主、保姆及其他應簽名位置使用平板手寫簽名；簽名圖層與簽署時間一併保存。
- 「逐項告知紀錄」是保姆講解合約時使用的輔助清單，不取代完整合約。

## 每一份已簽合約需要保存

- 合約範本版本與原始 PDF 雜湊值。
- 每個輸入欄位的值、頁碼與座標。
- 每一筆簽名的簽署人角色、簽署時間及簽名影像。
- 完成後不可覆寫的 PDF 成品與其雜湊值。
- 建立、修改、檢視及下載的稽核紀錄。

## 權限原則

- OWNER 可查看完整合約。
- 事主只能查看自己的家庭合約。
- 保姆只能查看被指派服務且 OWNER 核准開放的完整合約或摘要。
- 身分證件與其他高敏感資料不因「可看合約摘要」而自動開放。
- 前端不持有 Supabase service role key；所有讀寫皆由 Cloudflare Worker 驗證身分後執行。

## 尚待製作

1. 將來源 DOCX 確認版面後轉成固定 PDF 範本。
2. 逐頁標記文字欄位、勾選框與簽名位置座標。
3. 建立平板簽名元件、完成確認及防誤觸流程。
4. 產生不可覆寫的簽署完成版 PDF，並提供依權限查看與下載。

目前後台的合約表單與逐項告知清單屬於資料結構及流程 DEMO，不能冒充已完成的正式電子簽署文件。
